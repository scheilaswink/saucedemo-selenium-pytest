# Evidências dos bugs

Prints (PNG) e gravações (GIF) dos 10 bugs encontrados nos testes exploratórios do SauceDemo.

- **Print (PNG):** o erro aparece em uma tela parada.
- **Gravação (GIF) + `_final.png`:** o erro depende de uma ação, como clicar, digitar ou recarregar. O GIF mostra o passo a passo e o PNG `_final` mostra o resultado.

Padrão de nome: `BUG-número_usuário_o-que-acontece`

Cada imagem tem uma faixa vermelha na parte de baixo com o título do bug, o passo e a URL. O elemento com problema aparece contornado em vermelho.

Os relatórios completos estão em [`../BUGS_PARA_JIRA.md`](../BUGS_PARA_JIRA.md).
